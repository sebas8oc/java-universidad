Desde Windows borras solo sda5 + sda6 + sda7 - las 3 que están después de C:. NO toques las 4 primeras.
Abre diskmgmt.msc (click derecho Inicio > Administración de discos) - Verás en Disco 0, de izquierda a derecha:
NO BORRAR - dejar intacto:
- 499 MB NTFS Recuperación / Healthy (Recovery Partition) -> sda1
- 100 MB FAT32 EFI System Partition -> sda2 - esta es la de Windows, si la borras no bootea
- 16 MB Reservado -> sda3 (a veces ni se ve)
- C: 198.48 GB NTFS ShowOS CCA4F3CEA4F3B8D2 -> sda4 - tu Windows. Tiene letra C:
SÍ BORRAR - click derecho > Eliminar volumen (en este orden):
1. 977 MB Healthy (EFI System Partition) que está justo después de C: -> sda5 /boot/efi Debian D65B-4AB6. Tamaño clave 977MB, no 100MB.
2. 723.60 GB Healthy (Primary Partition) sin letra, aparece como RAW / Desconocido -> sda6 ext4 Debian 3b455185...
3. 7.87 GB al final -> sda7 swap
Si Eliminar volumen está gris en la de 977MB EFI, usa diskpart como admin:
diskpart
list disk
sel disk 0
list part
sel part 5  # la de 977MB
delete partition override
sel part 6  # la de 723GB (ahora será 6 tras borrar 5)
delete partition override
sel part 7  # swap (ahora 7 o 6, verifica con list part)
delete partition override
exit
Después de borrar:
Verás 786 GB No asignado (barra negra) después de C:.
- Click derecho en C: -> Extender volumen -> Siguiente -> pon 287000 MB -> Siguiente -> Finalizar.
- Queda: C: 500GB NTFS + ~486GB No asignado (negro) al final - ahí instalarás Omarchy ext4.
Verificación antes de borrar: Asegúrate que ~/RESPALDO_MITIMITI_2026-09-01:1 ya esté copiado a tu USB con ~/copiar_a_usb.sh:1 y du -sh coincida (366M). ¿Ya copiaste a USB o quieres que esperemos a verificar?
